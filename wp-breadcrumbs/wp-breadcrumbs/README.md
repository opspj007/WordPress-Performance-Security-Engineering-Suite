# WP Breadcrumbs

Lightweight, SEO-friendly breadcrumbs for WordPress.

## Features

- Automatic breadcrumb insertion
- `[wp_breadcrumbs]` shortcode
- Schema.org `BreadcrumbList` JSON-LD
- Pages and hierarchical page parents
- Categories, tags and custom taxonomies
- Custom post types
- WooCommerce shop and product categories
- Custom separator and Home label
- Lightweight CSS
- No external dependencies

## Installation

1. Upload `wp-breadcrumbs` to `wp-content/plugins/`.
2. Activate **WP Breadcrumbs** from **Plugins**.
3. Configure it under **Settings → WP Breadcrumbs**.
4. Use `[wp_breadcrumbs]` manually or enable automatic insertion.

## Shortcode

```text
[wp_breadcrumbs]
```

Custom class:

```text
[wp_breadcrumbs class="my-breadcrumbs"]
```
